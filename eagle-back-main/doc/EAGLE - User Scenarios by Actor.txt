2. SECONDARY SECRETARY SCENARIO
2.1 Patient Arrival at Center
Context: Patient arrives at secondary center in Douala
Secondary Secretary Actions:
1. Patient Welcome (08:30):
   - Identity document verification
   - ID document scan in system
   - Patient file creation/search
   
2. Request Registration:
   - Consultation reason entry
   - Requested specialty (Cardiology)
   - Initial urgency assessment (1-5)
   - Symptom photos if relevant
   
3. Order Number Assignment:
   - System generates ticket #2025-DLA-0045
   - Queue position: 3rd
   - Estimated wait time: 45 minutes
   
4. Patient Information:
   - Ticket with QR code delivery
   - Teleconsultation process explanation
   - Preparation instructions (fasting if necessary)
   
5. Network Notification:
   - Automatic alert to primary center
   - If urgency ≥ 3: Immediate notification
   - Real-time queue update

  - Delay/cancellation management

Conflict Management:

5. SPECIALIST DOCTOR SCENARIO
5.1 Consultation Preparation
Context: Dr. Nana, cardiologist, prepares consultation 09:15
Doctor Actions:
1. File Consultation (09:10):
   - Complete medical history reading
   - Recent vital signs analysis
   - Document/photo visualization
   - Attention point identification
   
2. Question Preparation:
   - Directed anamnesis to conduct
   - Physical exams to request
   - Diagnostic hypotheses
   - Potential additional exams
   
3. Technical Verification:
   - Video connection test
   - Audio quality verified
   - Reference documents opened
   - Prescription software ready
5.2 Video Consultation (09:15-09:40)
Standard Procedure:
Phase 1 - Anamnesis (5 min):
  - Patient + nurse greetings
  - Detailed symptom questions
  - Event chronology
  - Triggering/relieving factors
  
Phase 2 - Guided Physical Examination (10 min):
  - General patient inspection
  - Guided thoracic palpation (nurse)
  - Cardiac auscultation (stethoscope)
  - Lower limb edema verification
  
Phase 3 - Analysis & Discussion (10 min):
  - Observation synthesis
  - Shared diagnostic hypotheses
  - Additional exam recommendations
  - Initial therapeutic plan
  
Phase 4 - Prescriptions & Advice (5 min):
  - Electronic prescription writing
  - Therapeutic instructions
  - Hygiene-dietary advice
  - Follow-up planning

9. EMERGENCY MANAGEMENT
9.1 Critical Urgency Escalation (Level 5)
Scenario: Patient with suspected stroke arrives in Maroua
Automatic System Actions:
Immediate Alert (< 30 seconds):
  - Push notification all actors
  - On-call doctor wake-up
  - Emergency slot reservation
  - Neighboring center alert

Special Protocol:
  - Immediate consultation without waiting
  - Neurologist contacted automatically
  - Evacuation preparation if necessary
  - Local SAMU coordination
9.2 Degraded Mode
Scenario: Internet outage at secondary center
Contingency Actions:
Offline Mode Switch:
  - Local server activation
  - Offline consultation recording
  - Radio/telephone communication
  - Reconnection synchronization

Patient Rerouting:
  - Neighboring center redirection
  - Transport organized if critical
  - Waiting patient information
  - Non-urgent consultation postponement
